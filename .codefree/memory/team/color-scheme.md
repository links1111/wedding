婚礼请柬系统配色规范（方案一：法式轻奢）：主色调为干枯玫瑰粉 (#d4a5a5)，辅助色为灰蓝绿 (#84a59d)，背景采用暖灰白 (#faf7f5)，卡片使用纯白搭配细腻阴影，文字为深灰褐 (#4a403a)，点缀色为香槟金 (#c9a96e)。整体风格要求高级、有质感、青春但不幼稚，采用低饱和度莫兰迪色系。所有页面（包括主请柬、子卡片、回执页、管理后台）均需统一此配色方案，子卡片需根据类型（相遇、心动、约会、表白、在一起、旅行、求婚、订婚）使用对应的专属莫兰迪色调进行视觉区分。

8 种子卡片专属配色：
- 相遇 (meet): 干枯玫瑰粉
- 心动 (heartbeat): 浅玫瑰粉 (#e8c4c4)
- 约会 (date): 灰蓝绿
- 表白 (confess): 深玫瑰粉 (#b89090)
- 在一起 (together): 浅灰蓝绿 (#a3c4bc)
- 旅行 (travel): 深灰蓝绿 (#6a8a85)
- 求婚 (propose): 香槟金
- 订婚 (engage): 干枯玫瑰粉

风格定位：法式轻奢，温柔高级，低饱和度，中性背景，克制点缀。

婚礼请柬系统配色规范：摒弃灰色、深红/酒红等沉闷或过于传统的色调，采用青春、有活力、高级且不俗气的明亮配色方案。用户偏好清新、阳光、现代的风格（如薄荷绿、天空蓝、柠檬黄、樱花粉、薰衣草紫等明亮色调），拒绝灰暗或老气的颜色。具体配色方案需经用户确认选择后应用。

婚礼请柬系统配色规范：摒弃灰色系，采用青春、有活力、高级且不俗气的配色方案。
1. 主色调：清新薄荷绿 (#4ecdc4) 或 天空蓝 (#74b9ff) 或 柠檬黄 (#fdcb6e) 等明亮色调，根据具体页面风格选择。
2. 辅助色：珊瑚橙 (#ff6b6b) 或 樱花粉 (#fd79a8) 或 薄荷绿 (#00b894) 等温暖或清新色调。
3. 背景：浅米白 (#f7fff9) 或 纯白 (#ffffff) 或 奶油白 (#fff9f0) 等明亮干净背景。
4. 卡片：半透明白或纯白，搭配主色调阴影或渐变边框。
5. 文字：深灰蓝 (#2d3436) 或 咖啡棕 (#634226) 等清晰易读且温暖的深色。
6. 点缀色：柠檬黄、薰衣草紫、珊瑚红等活泼色彩。
7. 整体风格：清新、青春、活力，避免沉闷的灰色和过于传统的红色。
