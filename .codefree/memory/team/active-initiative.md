婚礼请柬系统当前工作流与待办事项：
1. 编辑页面右上角“查看请柬”按钮需修复跳转逻辑，确保正确跳转至请柬页面。
2. 管理页面右上角“查看请柬”按钮需修复跳转逻辑，从 /api/a/:token/meta 获取真实请柬 token 后跳转，避免跳转后页面为空。
3. 设置页面布局已重构为左右分栏：左侧为时间轴样式卡片列表（宽度 220px），右侧为预览与设置区。
4. 设置页面左侧时间轴设计：垂直渐变金线为主干，节点为圆点（主请柬节点更大更亮），选中节点高亮发光；节点右侧显示卡片标题和类型标签；每个子卡片节点右侧放置上移（↑）、下移（↓）、删除（×）图标按钮，无文字。
5. 子卡片设置项中移除独立的删除、上移、下移按钮，统一移至左侧时间轴节点旁。
6. 子卡片需针对 8 种类型（相遇、心动、约会、表白、在一起、旅行、求婚、订婚）分别设计独立视觉装饰，避免简单重复。
7. 卡片预览尺寸需与 index.html 中实际卡片保持一致（max-width: 460px），桌面端预览栏宽度需足够容纳完整卡片，避免留白或比例失真。
8. 轮播图切换需实现平滑交叉淡入淡出效果：滚动到新卡片时，旧图片淡出的同时新图片第一张淡入，不等待预加载完成，过渡时间 0.8 秒。
9. 音乐播放需支持用户交互后自动恢复：每次用户点击页面任意位置（除特定区域外）均尝试恢复有声播放，解决浏览器自动播放策略限制。
10. 整体配色方案已确定为莫兰迪粉 + 灰蓝绿法式轻奢风格：主色干枯玫瑰粉 (#d4a5a5)，辅助色灰蓝绿 (#84a59d)，背景暖灰白 (#faf7f5)，文字深灰褐 (#4a403a)，点缀香槟金 (#c9a96e)。
11. 每次代码修改后必须执行 git commit。
