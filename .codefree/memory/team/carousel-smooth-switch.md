婚礼请柬系统轮播图切换规范：平滑交叉淡入淡出，滚动到新卡片时旧图片淡出的同时新图片第一张淡入，不等待预加载完成，过渡时间 0.8 秒。预加载机制：切换前需后台预加载新卡片的图片列表，确保后续轮播流畅。自动播放：切换后轮播图需自动继续播放，定时器在淡入淡出完成后重新启动。实现注意事项：performFadeSwitch 过渡完成后，必须清除所有新图片的 inline style opacity，让 CSS .slide { opacity: 0 } 和 .slide.active { opacity: 1 } 的样式控制生效，避免 inline style 覆盖 CSS class 导致 active 类切换失效。轮播图自动播放间隔为 4 秒。
