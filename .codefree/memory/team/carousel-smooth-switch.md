婚礼请柬系统轮播图切换规范：
1. 平滑交叉淡入淡出：滚动到新卡片时，旧图片淡出的同时新图片第一张淡入，不等待预加载完成，过渡时间 0.8 秒。
2. 预加载机制：切换前需后台预加载新卡片的图片列表，确保后续轮播流畅。
3. 自动播放：切换后轮播图需自动继续播放，定时器在淡入淡出完成后重新启动。
4. 索引计算逻辑：carShow 函数直接使用传入的索引值作为 carIdx，不再基于 slides.length 重新计算，确保 carList.length 与 slides.length 一致时索引正确。
5. 所有新图片在过渡完成后需设置 opacity: 1，确保多张图片轮播时可见。
