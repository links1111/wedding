婚礼请柬系统轮播图切换规范：平滑交叉淡入淡出，滚动到新卡片时旧图片淡出的同时新图片第一张淡入，不等待预加载完成，过渡时间 0.8 秒。预加载机制：切换前需后台预加载新卡片的图片列表，确保后续轮播流畅。自动播放：切换后轮播图需自动继续播放，定时器在淡入淡出完成后重新启动。实现注意事项：performFadeSwitch 中过渡完成后必须清除新图片的 inline style opacity 和 transition，让 CSS class（.slide opacity:0 / .slide.active opacity:1）重新控制可见性，否则所有图片叠在一起导致 active 类切换失效、图片看似不轮播。carShow 函数中 carIdx 直接使用传入索引，不要重复取模计算。
