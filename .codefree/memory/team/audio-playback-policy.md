婚礼请柬系统音乐播放策略：
1. 浏览器自动播放限制：禁止在用户无交互时自动播放有声音频。
2. 用户交互触发：每次用户点击页面任意位置（除音乐按钮和回执表单区域外）均尝试恢复有声播放。
3. 音乐按钮控制：点击音乐按钮可播放/暂停音乐。当用户主动点击音乐按钮关闭音乐后，点击页面不再自动播放；再次点击音乐按钮后，点击页面恢复自动播放逻辑。
4. 状态管理：使用 musicClosed 状态区分“音乐被关闭”和“音乐被暂停”。只有当 musicClosed 为 false 时，点击页面才会尝试播放音乐。
5. 错误处理：如果有声播放失败，自动尝试静音播放；如果静音播放也失败，尝试暂停后重置到开头再重新播放。

项目中的背景音乐播放受浏览器自动播放策略限制，禁止在用户无交互时自动播放有声音频。修复方案是在用户交互（点击页面任意位置或音乐按钮）时触发播放尝试。具体实现包括： 1. 移除首次交互单次触发逻辑，改为全局点击事件监听，确保每次用户操作都尝试恢复播放。 2. 音乐按钮点击事件使用 setTimeout 延迟执行播放，确保在用户交互上下文中调用。 3. 有声播放失败时自动降级为静音播放，并在用户交互时恢复声音。 4. 避免在 CSS 中出现多余的闭合括号等语法错误，确保样式正常加载。
