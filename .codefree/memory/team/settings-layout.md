婚礼请柬系统设置页面布局与交互规范：整体采用左右分栏结构。左侧为时间轴样式卡片列表（宽度 220px），右侧为内容区（预览 + 设置）。左侧时间轴：垂直渐变金线为主干，卡片为节点（圆点）。主请柬节点更大更亮带金色发光；选中节点实心金色发光且文字变金色。节点内容显示卡片标题与类型标签。每个子卡片节点右侧在 hover 时显示三个图标按钮：上移箭头、下移箭头、删除叉号，均为纯图标无文字。右侧内容区：顶部为预览栏（宽度 492px，与 index.html 卡片宽度一致），底部为设置表单。主请柬编辑时预览栏显示主请柬完整预览（调用 renderMainCardPreview），子卡片编辑时显示对应子卡片预览（调用 renderCardPreview）。预览栏在主请柬编辑时显示，子卡片编辑时也显示。移动端响应式：窄屏时左侧时间轴变为顶部横向滚动，操作按钮水平排列。
