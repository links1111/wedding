婚礼请柬系统设置页面布局与交互规范：采用左右分栏结构。左侧为时间轴样式卡片列表（宽度 220px），垂直渐变金线作为时间轴主干，节点为圆点，主请柬节点更大更亮，选中节点高亮发光，节点右侧显示卡片标题和类型标签，每个子卡片节点右侧放置上移（↑）、下移（↓）、删除（×）图标按钮，无文字。右侧内容区分为上下两部分：上部为预览区（宽度 492px，固定显示当前编辑卡片的完整预览，主请柬显示完整请柬内容，子卡片显示对应卡片预览），下部为设置项（可滚动）。移动端响应式：时间轴变为顶部横向滚动，操作按钮水平排列。

婚礼请柬系统设置页面布局与交互规范：
1. 整体布局：采用左右分栏结构。左侧为时间轴样式卡片列表（宽度 220px），右侧为内容区（预览 + 设置）。
2. 左侧时间轴：
   - 垂直渐变金线作为时间轴主干
   - 每个卡片是一个节点（圆点），主请柬节点更大更亮（带金色发光）
   - 选中节点圆点变为实心金色并发光，文字变为金色
   - 节点内容显示卡片标题 + 类型标签
   - 每个子卡片节点右侧放置三个图标按钮：↑（上移）、↓（下移）、×（删除），纯图标无文字
   - hover/active 时右侧显示操作按钮
3. 右侧内容区：
   - 顶部预览区：实时显示当前编辑卡片的预览效果
   - 主请柬编辑时：左侧预览栏显示主请柬完整预览（调用 renderMainCardPreview），右侧显示主请柬配置表单
   - 子卡片编辑时：左侧预览栏显示对应子卡片预览（调用 renderCardPreview），右侧显示子卡片编辑表单
   - 预览栏显示/隐藏逻辑：主请柬编辑时显示预览栏，子卡片编辑时也显示预览栏
4. 卡片大小规范：预览卡片宽度与 index.html 中的实际卡片保持一致（max-width: 460px），桌面端空间充足，预览区宽度设为 492px（460px 卡片 + 16px padding × 2）
5. 子卡片设计：8 种卡片类型需有独立的视觉装饰和样式，避免简单重复
