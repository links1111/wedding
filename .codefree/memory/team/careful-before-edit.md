用户要求：每次修改代码后必须 git commit。修改前务必仔细排查问题根因，一次性修改正确，强调错误修改会导致严重事故。排查时要完整阅读相关代码和布局层级后再动手，不要急于修改。用户对"桌面端空间有限"这类错误假设非常不满，要求认真对待用户的明确指令（如"保持和 index 一致"）。
